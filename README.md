# D & D BBQ Zone — Restaurant & Hotel Website

Official website for **D & D BBQ Zone**, located in **Butwal - 14, Belbariya, Rupandehi, Nepal**.

A modern, responsive, and high-performance website showcasing live charcoal barbecue skewers, authentic Nepali cuisine, private garden cottages, event hosting, and comfortable hotel/lodge accommodation.

---

## 🌟 Key Features

* **Sizzling Live BBQ Menu:** Chicken Sekuwa, Special Pork Ribs BBQ, Mutton BBQ & Tass, Tandoori Paneer Tikka, Steaming Momos, Chowmein, and Chilled Beverages.
* **Private Dining Cottages & Garden:** Highlighted thatched gazebo cottages for family dinners, friends reunions, and birthday celebrations.
* **Hotel & Lodge Accommodation:** Showcase of Deluxe AC rooms, Standard rooms, and Family suites with amenity details.
* **Interactive Photo Gallery:** Filterable by category (*BBQ & Food*, *Cottages & Garden*, *Hotel Rooms*, *Celebrations*) with a responsive Lightbox modal.
* **Location & Interactive Map:** Embedded Google Maps targeting Belbariya, Butwal-14 (`27°40'31"N 83°25'30"E`) with 1-click turn-by-turn directions.
* **Dual-Purpose Reservation System:** Dynamic form for reserving dining tables / cottages or booking hotel rooms with instant validation and AJAX submission.
* **Local Tourism Highlights:** Discover nearby Lumbini, Jitgadhi Killa, Hill Park, and Manimukunda Sen Park.

---

## 🚀 Tech Stack

* **HTML5:** Semantic, accessible, and SEO-optimized structure.
* **CSS3:** Custom design tokens, responsive CSS grid/flexbox, animations, mobile drawer.
* **JavaScript (ES6+):** Vanilla JavaScript for smooth scrolling, gallery filters, lightbox viewer, and reservation handling.

## 🌐 Deploy to GitHub Pages

To make this site live for free on GitHub Pages:
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages** in the GitHub repository.
3. Under **Branch**, select `main` branch and `/ (root)` folder.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/`!
